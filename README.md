# 牛马的薪跳

> 一个桌面悬浮小窗 + 安卓桌面小组件，实时显示你今天已经赚到的钱、每秒进账、工龄，以及距离下班 / 退休还有多久。全部数据在本机计算，不联网、不上传。
>
> 本仓库为「上班鼓励器」的重命名 / 重新打包版本，提供 Windows 与 Android 安装包。

## 功能
- 实时显示：今日已赚、每秒进账、工龄、距离下班 / 退休倒计时
- 桌面悬浮窗：可拖动、贴边隐藏、置顶、透明度调节
- 多种版式：详细版 / 简易版 / 横版
- 6 套配色主题（经典 / 墨绿 / 深空 / 极夜 / 绯红 / 蓝调）
- 开机自启、托盘运行
- 安卓桌面小组件（实时数字）

## 下载
前往 [Releases](https://github.com/FEFKNCQ/NMDXT/releases) 下载对应安装包：
- **Windows**：`NMDXT-win64-setup.exe`（64 位，绝大多数电脑用这个）；老旧的 32 位系统用 `NMDXT-win32-setup.exe`
- **Android**：`NMDXT-1.apk`

> 桌面端版本 **v9.14**，安卓端版本 **1.0**。

## Windows 安装与使用
1. 把 `NMDXT-win64-setup.exe` 放进任意一个你自己建的文件夹（**不要**放在 `C:\Program Files` 这类需要管理员权限的目录）。
2. 双击运行，首次启动出现在屏幕右下角。
3. 配置会在你第一次「保存设置」时自动生成到用户目录，无需随包携带。
4. 想开机自启：右键小窗 → 勾「开机自启」；想退出：右键 → 「退出」（右上角 ✕ 只是最小化到托盘）。

> 首次打开显示的是示例数据（月薪 3000、9:00–18:00）。点右上角齿轮打开设置，改成你自己的月薪、上下班时间、入职日期。

**常见提示（都正常）：**
- Windows 弹出「已保护你的电脑」(SmartScreen)：软件未购买数字签名证书，不是病毒。点「更多信息」→「仍要运行」。
- 杀毒软件报可疑：程序用 ps2exe 把 PowerShell 脚本打包成单文件 exe，常被误判，加信任 / 白名单即可。
- 双击没反应：多半已在托盘运行，再双击只是唤起已有窗口。

**系统要求：** Windows 10 / 11；仅依赖系统自带的 .NET Framework 与 PowerShell，无需额外安装；不需要管理员权限；支持多显示器与不同缩放比例（125% / 150% 等）。

## 安卓安装与使用
1. 把 `NMDXT-1.apk` 传到手机（微信 / QQ / 数据线 / 网盘均可）。
2. 手机上点开安装；若弹出「不允许安装未知来源的应用」，在弹窗里点「设置」打开允许开关再返回继续。
3. 已装过旧版本直接覆盖安装即可，数据不会丢，不用先卸载。
4. 首次打开按自己的月薪、上下班时间、工作日做设置。
5. 加桌面小组件：长按桌面空白处 → 选「小组件 / 窗口小工具 / 服务卡片 / 插件 / 原子组件」→ 找到「牛马的薪跳」→ 拖到桌面。
6. 部分机型需给应用开「自启动 / 后台运行」权限，否则小组件数字可能不实时刷新。

> 适用 Android 8.0 及以上（2018 年后上市的大部分手机满足）。本安装包为调试签名版本，个人之间安装使用没问题，但不能直接上架应用商店。

## 设置项
- 月薪、每月工作日、上下班时间、午休时间
- 入职日期（算工龄）、出生日期 + 退休年龄（算退休倒计时）
- 透明度 1%–100%（1% 最淡，100% 实心）
- 版式：详细 / 简易 / 横版——点一下立刻预览，保存后固定
- 配色主题：6 套，点主题卡片即时预览，点「取消」会还原
- 窗口大小缩放

## 数据与隐私
- 工资、生日等数据只写入你本机配置文件：`%APPDATA%\上班鼓励器\config.json`（文件管理器地址栏输入 `%APPDATA%` 回车即可进入 Roaming 目录）。第一次打开时还没有这个文件，点过一次「保存」之后才会生成。
- 程序不联网、不上传、不收集任何信息。
- 想恢复出厂设置：退出程序 → 删掉这个文件夹 → 重新打开。

## 卸载
1. 右键小窗 → 退出（若开过开机自启，先在设置里关掉，会一并删除启动项）。
2. 删除 exe 文件。
3. 删除 `%APPDATA%\上班鼓励器` 文件夹。
